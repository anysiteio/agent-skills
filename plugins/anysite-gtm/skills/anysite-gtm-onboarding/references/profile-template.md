# GTM profile template

Write the profile to `~/.claude/skills/anysite-gtm-profile/SKILL.md` exactly in this
shape. Keep the frontmatter verbatim except the company name — its description is what
makes other skills load the profile. Omit a row the user left `unknown` only if it would
be noise; otherwise keep it as `unknown` so the gap stays visible.

```markdown
---
name: anysite-gtm-profile
description: The user's saved GTM context for <Company> - offer, ICP, buyer personas, competitors, best customers, buying signals, CRM and outreach voice. ALWAYS consult this before sourcing companies or people, scoring, prospecting, qualifying inbound, finding lookalikes, sweeping signals or drafting outreach - it is the default ICP, persona and offer unless the user states otherwise in the current request. Generated by /anysite-gtm-onboarding - re-run it to change.
---
```

## How other skills use it

- Current request beats the profile: if the user states a different ICP or persona for
  this task, use theirs and do not overwrite the profile.
- A section that is `unknown` is asked about once, in the skill that needs it, and the
  answer is offered back into the profile.
- The profile never replaces `anysite-crm-profile`: CRM field mapping and write rules
  stay there.
